## Fixed Decisions

1. **Remove, do not hide:** `page` leaves `PANEL_IDS` and `PANEL_REGISTRY`; no Page item remains in Window and no parking host is rendered.
2. **No version bump:** v5's structural shape is unchanged. `normaliseV5()` already treats membership as registry-driven; unknown `page` data is discarded like any obsolete ID.
3. **Preserve surviving layout:** never reset the full stored layout merely because `page` is present. Remove it from groups/floats/panel records, drop now-empty groups/floats, repair `active` to the first surviving member, and retain dock widths, remaining order, heights, collapse and float rects.
4. **Legacy readers remain tolerant:** raw v2/v3/v4 payloads may contain the string `page`. Keep raw-input typing broad enough to parse it, then filter through `isKnownPanelId`; never cast the obsolete string back to current `PanelId`.
5. **No UI work here:** T-090b already deletes `PageSection.vue` and the `page` branch. T-090c changes only registry/layout model files and focused tests.
