Establish a render-only transient payload and a CanvasKit overlay which can draw distance annotations between an existing selection and a named hovered target. No pointer event sets the payload in this packet; T-094b activates it.

## Fixed Decisions

1. State is exactly `distanceMeasurement: { targetId: string } | null`. Selection remains authoritative in `selectedIds`; no duplicate IDs, coordinates, or modifier bits are stored.
2. Add `setDistanceMeasurement(measurement: EditorState['distanceMeasurement']): void`. If current and new `targetId` match (including both absent), return; otherwise assign and call `ctx.requestRepaint()`.
3. The overlay payload is exactly `distanceMeasurement?: { targetId: string } | null`; it has no persisted, undo, document, command, or serialisation path.
4. Geometry supports only visible, unrotated (`rotation === 0`) nodes. Resolve all selected nodes and target fresh per paint. If selection is empty, target is selected/missing/invisible/rotated, or any selected node is missing/invisible/rotated, draw nothing.
5. Use `computeAbsoluteBounds(selectedNodes, graph.getAbsolutePosition)` and `computeAbsoluteBounds([target], graph.getAbsolutePosition)`. Never use `computeSelectionBounds` here.
6. A horizontal dimension exists only when the rectangles are horizontally disjoint; its `from`/`to` are the facing edges and `position` is the midpoint of their vertical overlap. A vertical dimension follows the same rule using facing y edges and the midpoint of horizontal overlap. A diagonal pair shows both. Overlap/containment yields no dimension on that axis; complete overlap yields none.
7. Draw all lines in screen space with `r.auxStroke.setStrokeWidth(1)`, `setColor(r.selColor())`, and `setPathEffect(null)`. Draw extension lines from facing edges, a dimension line outside the gap by 8 screen pixels, and 4-screen-pixel end ticks. Label each dimension via `drawRulerBadge` with `${formatUnitValue(distance, r.documentUnits)} ${r.documentUnits.unit}`.
8. This draw path allocates no CanvasKit wrapper. Do not create a `Path`, `Paint`, `Font`, `Image`, shader, surface, cache, or cleanup hook.

## Acceptance Criteria

- [ ] `distanceMeasurement` is transient editor state initialised to `null`, with an equality-suppressing repaint setter.
- [ ] The renderer receives the exact payload and draws it after snap guides.
- [ ] Nested unrotated selection bounds use absolute graph positions, never local `computeSelectionBounds` coordinates.
- [ ] Separate horizontal, vertical, and diagonal rectangles produce the fixed edge-to-edge dimensions.
- [ ] Overlap, containment, selected target, missing/invisible node, and any rotation produce no unsafe annotation for that case.
- [ ] Labels honour current px/mm/cm/in units and include their suffix.
- [ ] The overlay creates no CanvasKit-owned object and alters no document state.
