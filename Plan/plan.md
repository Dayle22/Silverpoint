# Plan

OpenPotlood is being developed in small, executable steps. Read `Plan/endgoal.md`, this index, and only the packet for the selected step; status is recorded only here.

**Status vocabulary — these three values are the only ones allowed in the Status column.**

| Status | Means | What exists |
| --- | --- | --- |
| To Do | Not executable yet. | A brief or dependency-locked follow-up. Expand/reconcile it after its named predecessors are Done. |
| Ready | Expanded packet, ready to execute. | A full packet with verified starting state, scope and gates. Execute this one. |
| Done | Executed; source gates and the browser check passed. | The change is in the source. Desktop delivery is tracked separately by the Delivery notes below, not by this column. |

Per-step detail — verification evidence for Done, expansion findings for Ready — lives in the packet file under `## Status record`, not in this table.

**Delivery policy (set 2026-08-14, extended 2026-08-18).** Packets stop at source gates, then close with a browser check on the dev server: `cd App && bun run dev` (Vite, port 1420, hot reload). Do not build the desktop app, run the NSIS installer, or bump the version files in `package.json` / `desktop/tauri.conf.json` / `desktop/Cargo.toml` unless the user explicitly asks for a build in that session, or the change cannot be proven any other way — Tauri config, Rust, icons, the generated `desktop/generated/menu.json`, or an `IS_TAURI`-only surface. Builds are batched across several completed packets, not run per packet.
